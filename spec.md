# ZeroWasteKitchen — Eco-Friendly Kitchen Products Database

## Problem
Zero-waste kitchen shoppers face greenwashing, no durability data, and no
cost-per-use analysis. Existing sites (The Good Trade, EarthHero) are either
marketplaces or shallow listicles. Nobody verifies claims or tracks how long
products actually last.

## Solution
Database of 55 plastic-free kitchen products with verified materials, durability
ratings, and honest cost-per-use data. Anti-greenwashing stance backed by data.

### Core features
1. **Product Database** — 55 products filterable by category, material, durability,
   dishwasher-safe, price
2. **Durability Tracker** — how long each product actually lasts (community data)
3. **Cost-Per-Use Calculator** — upfront cost / expected uses = true value
4. **Greenwashing Detector** — flags products with unverified eco-claims
5. **Japan Eco Products** — hidden gems like hinoki cutting boards, beeswax wraps

### Killer differentiators
- Durability data (nobody tracks this)
- Cost-per-use analysis (expensive upfront but saves money?)
- Japanese eco-products section (hinoki, binchotan, beeswax wraps from Japan)
- Anti-greenwashing with certification verification

## Tech Stack
- GitHub Pages (static), Vanilla JS + Tailwind CSS
- data/products.json (existing 55 products, needs ASIN fill)
- GA4 + Clarity

## MVP Scope
1. Remove "No affiliate links" copy from index.html
